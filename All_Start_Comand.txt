Start AP! first, then Blazor, then React Admin, and finally RabbitMQ Management.

build everything
dotnet build SportsSln.sln

build API
dotnet build OrderManagement.API/OrderManagement.API.csproj

build Blazor
dotnet build BlazorPortal/BlazorPortal.csproj

# Terminal 1 - Backend
docker-compose up -d

API:
dotnet run --project OrderManagement.API/OrderManagement.API.csproj

Blazor:
dotnet run --project BlazorPortal/BlazorPortal.csproj

React Admin:
cd admin-dashboard
npm start

RabbitMQ Management:

— Blazor
http://localhost:5017 
— API
http://localhost:5292/swagger 
— React Admin
http://localhost:3000 
- RabbitMQ Management
http://localhost:15672 


force to stop
Get-Process | Where-Object {$_.Name -like "dotnet*"} | Stop-Process -Force
